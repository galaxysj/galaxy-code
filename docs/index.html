Permissions

You decide how much the agent can do.

Pick a permission mode per chat. When an action needs you, the approval takes the composer's place until you answer.

Auto
A safety model approves routine work and asks you about risky actions.
Ask for Approval

Accept Edits
File changes inside the working directory run automatically. Other actions ask for approval.
Full Access
Everything runs without asking. Use with care.

Get started

Start with your project.

  1. Add a project folder in the app.
  2. Connect an agent in Settings → Providers or Subscriptions: sign in, or add an API key.
  3. Enable models in Settings → Models as needed.
  4. Start a new chat, pick a provider and model, and describe your task.

Building from source requires Node.js 22.12 or later. Distribution scripts currently target macOS.

Terminal
# Clone and run in development mode
$ git clone https://github.com/galaxysj/galaxy-code.git
$ cd galaxy-code
$ npm ci
$ npm run dev

# Or package a macOS app
$ npm run dist:dmg

Stop switching between agent tools.
